#HumanSight
HumanSight helps identify images that contain people, making it easier to review and organize image datasets for AI training.

Overview
HumanSight scans images for the presence of people and supports dataset curation workflows. Use it to find relevant images for review before including them in a training dataset.

Features
Scan images for people
Help organize images for dataset review
Support image curation for AI training workflows
Responsible use
Only scan images you have the right to use. Before using images to train AI systems, confirm that their collection and use comply with applicable laws, licensing terms, and consent requirements.
